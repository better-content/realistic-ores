Realistic Ores Hosted PNG Pack

Contents
- textures/overlays/: original transparent 16x16 ore overlays
- textures/stone/: overlay composited onto vanilla stone
- textures/deepslate/: overlay composited onto vanilla deepslate side/top/bottom
- ore_spec.json: JSON-friendly ore metadata, y bands, and recommended vanilla feature disables

Scope
- Assets only
- No generated blockstates/models
- No dynamic texture composition
- No worldgen JSON emitted here

Conventions
- Stone block texture file: <ore_id>_stone.png
- Deepslate block texture files:
  - <ore_id>_deepslate_top.png
  - <ore_id>_deepslate_bottom.png
  - <ore_id>_deepslate_side.png
